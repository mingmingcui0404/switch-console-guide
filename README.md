# Switch Console Guide

A static, SEO-focused landing page for a Nintendo Switch buying guide.

## Files

- `index.html` - single-page landing site with conversion copy, metadata, Open Graph tags, and Product structured data.
- `assets/switch-console.svg` - local product-style illustration used in the hero and social preview.
- `robots.txt` - crawl rules and sitemap reference.
- `sitemap.xml` - canonical URL for Cloudflare Pages indexing.
- `wrangler.toml` - Cloudflare Pages project config.

## Deployment

This project is designed for Cloudflare Pages.

- Project name: `switch-console-guide`
- Build output directory: `.`
- Build command: none
